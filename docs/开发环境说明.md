# 字有答案 · 开发环境说明

## 本地启动

```bash
./启动服务.sh
```

首次运行会自动：创建 `.venv` → 安装依赖 → 初始化数据库 → 启动服务（127.0.0.1:8150）。
之后每次只需执行最后一步，约 2 秒。

Windows 用户可双击 `启动本地网站.cmd`（纯静态浏览，不含后端功能）；
要体验注册登录请用 `启动服务.sh` 或手动执行 uvicorn。

## 管理员登录

```bash
.venv/bin/python -m server.set_password oracleanswered@gmail.com
```

交互式输入密码后，用该邮箱在登录页登录，进入「管理后台」。

## 数据库切换

| 场景 | 配置 | 数据库 |
|---|---|---|
| 本地开发 | 不设 `DATABASE_URL` | SQLite → `data/oracle.db` |
| 线上部署 | `DATABASE_URL=postgresql+psycopg://...` | PostgreSQL |

业务代码无任何 SQLite 特有语法，切换只改环境变量。

## 常用命令

```bash
# 启动
./启动服务.sh

# 重新导入内容（已存在的数据不覆盖）
.venv/bin/python -m server.seed

# 设密码
.venv/bin/python -m server.set_password <邮箱>

# 接口文档（服务启动后访问）
# http://127.0.0.1:8150/api/docs

# 改端口
PORT=8200 ./启动服务.sh
```

## 内容来源说明

前台内容**以数据库为准**，由 `web/content-sync.js` 在页面加载后拉取
`GET /api/content` 覆盖静态 `web/content.js`：

- 后台添加/修改/下架甲骨字、情绪图标 → **用户侧刷新即可见**
- 静态 `content.js` 作为兜底：接口不可用时站点照常工作
- 用户历史上保存过的字即使已下架，仍能在「我的片刻」正常显示（不会被抽到，但不会报错）

改后台内容后需刷新页面才会生效（不做实时推送）。
